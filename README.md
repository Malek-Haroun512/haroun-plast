# صفحة تحميل تطبيق هارون بلاست

مجلد جاهز للنشر — ارفعه كما هو واحصل على رابط تحميل فوري.

## المحتويات

| ملف | الوصف |
|---|---|
| `index.html` | الصفحة كاملة (عربية، بدون أي ملفات خارجية) |
| `icon.png` | شعار التطبيق (512×512) |
| `HarounPlast-1.0.0-arm64-armv7a.apk` | ملف التطبيق نفسه (≈54 ميغابايت) |

## النشر — GitHub Pages (مجاني ودائم)

1. أنشئ حسابًا على [github.com](https://github.com) (إن لم يكن لديك).
2. اضغط **+** أعلى الصفحة ← **New repository** ← اسمه `haroun-plast` ← **Public** ← Create.
3. في صفحة المستودع اضغط **uploading an existing file** وأسقِط ملفات هذا المجلد الثلاثة.
4. اذهب إلى **Settings ← Pages** ← في *Build and deployment* اختر Source: **Deploy from a branch**، والفرع: **main** والمجلد: **/(root)** ← Save.
5. بعد دقيقة أو دقيقتين يظهر الرابط أعلى الصفحة نفسها، على الشكل:
   `https://<اسمك>.github.io/haroun-plast/`
6. افتح الرابط من هاتفك واختبر زر التحميل.

## التحديث لاحقًا (إصدار جديد)

- استبدل ملف الـAPK القديم بالجديد **بنفس الاسم** ← تتحدث الصفحة تلقائيًا دون أي تعديل.
- أو إن غيّرت الاسم، عدّل الاسم داخل `index.html` في سطر `href="..."`.

## بدائل عن GitHub

- **Netlify Drop**: أدخل [app.netlify.com/drop](https://app.netlify.com/drop) وأسقط المجلد — يعطيك رابطًا فورًا (تأكد من حدّ حجم الملف قبل الرفع).
- أي استضافة ثابتة (Static) تدعم ملفات ~60 ميغابايت تعمل.
